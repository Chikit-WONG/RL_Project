# 图表阅读指南

## 推荐报告主线

本项目最终不是简单地说“某个算法成功率最高”，而是展示一个实验设计逐步变成熟的过程：

1. 先用 Gymnasium 随机图做诊断。
2. 同时强调 Gymnasium 标准 8x8 是重要标准基准，不能和低 p 随机图混为一谈。
3. 发现很多低 p 随机图 oracle success 本身接近 0，因此不适合做公平算法对比。
4. 改用 controlled stochastic maps 作为主比较环境。
5. 在 controlled random 8x8 上比较 7 个 tabular RL 算法。
6. 用 ablation 和 Optuna 解释为什么 Optimistic Q-learning 表现最好。

## 02_main_controlled_results

这些是主要结果图。

- `standard_4x4_slippery_only_success.png`
  - 标准 4x4 slippery map。
  - 用来说明 stochastic FrozenLake 不应期待 100% 成功率。

- `designed_4x4_exact4holes_aggregate.png`
  - 设计的 4x4 map，每张图固定 4 个洞。
  - 用来避免随机图过于简单。

- `stochastic_success_heatmap.png`
  - 总体成功率热力图。
  - 快速展示不同环境下算法表现。

- `random8_final_success_heatmap_by_map.png`
  - controlled random 8x8 每张地图的最终成功率。
  - 用来比较算法在不同地图上的稳定性。

- `random8_oracle_gap_heatmap_by_map.png`
  - learned policy 与 Value Iteration oracle 的差距。
  - gap 小代表接近最优。

- `random8_auc_heatmap_by_map.png`
  - AUC 衡量整个训练过程表现，不只看最终点。
  - Dyna-Q 的价值常体现在 AUC 和早期学习速度。

- `random8_final_success_points_by_probability.png`
  - 每个点是一张地图。
  - 用来解释 map-to-map variance。

- `random8_learning_curves_all_maps_panel.png`
  - 20 张 controlled random 8x8 的逐图学习曲线。
  - 适合答辩时解释“不是所有地图难度一样”。

- `exploration_ablation_fixed_8x8.png`
  - 探索策略 ablation。
  - Optimistic initialization 表现最好，说明 sparse reward 下主动探索很重要。

- `reward_propagation_ablation_fixed_8x8.png`
  - reward propagation ablation。
  - 对比 eligibility traces、Dyna-Q、n-step 等方法。

- `optuna_best_scores.png`
  - Optuna 调参结果。
  - 说明参数搜索不是随便选参数。
  - 这张图使用后续正式 tuned validation scores，已经剔除早期 screening 中异常偏低的 Double Q。

## 03_diagnostic_gymnasium8

这些图不是主排名依据，而是用来解释为什么要做 controlled map design。

- `gym8_final_success_heatmap.png`
  - 右侧的 standard8 列是重要标准对比，可以看到多个算法能学到较高成功率。
  - 左侧很多低 p random maps 所有算法都接近 0。

- `gym8_oracle_gap_heatmap.png`
  - 结合 oracle 看：standard8 是可解标准图，而有些低 p random maps 不是算法没学好，而是 oracle 自己也很低。

- `gym8_mean_learning_curve.png`
  - 混合很多不同难度地图后的平均曲线。
  - 不适合单独作为算法 ranking。

- `gym8_summary_contact_sheet.png`
  - Gymnasium 诊断实验总览。

- `gym8_per_map_contact_sheet.png`
  - 每张 Gymnasium 地图学习曲线总览。
