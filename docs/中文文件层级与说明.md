# 中文文件层级与说明

这是 GitHub 上传版的文件结构说明。建议把整个文件夹作为原仓库中的一个新目录提交，例如：

```text
enhanced_frozenlake_stochastic/
```

不要直接覆盖原仓库已有文件。

## 顶层结构

```text
.
|-- README.md
|-- GITHUB_BRANCH_WORKFLOW.md
|-- code/
|-- figures/
|-- results_csv/
|-- docs/
```

## `code/`

```text
code/focused_random_map/
```

这里是可运行代码。

主要脚本：

- `run_standard_4x4_focused.py`：标准 4x4 slippery 实验。
- `plot_standard_4x4_slippery.py`：标准 4x4 绘图。
- `run_random8_learning_curves.py`：designed 4x4 和 random 8x8 long-budget 曲线。
- `make_long_budget_report_assets.py`：从 CSV 生成图像和汇总表。
- `enhanced_frozenlake.py`：环境和算法实现。
- `map_env_utils.py`：显式地图和评估工具。
