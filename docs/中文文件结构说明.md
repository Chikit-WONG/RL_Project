# 中文文件结构说明

本提交包按最终报告叙事重新整理：先强调 Gymnasium 标准 8x8 是重要标准基准，再展示 Gymnasium 随机图诊断实验，说明为什么需要 controlled maps，最后用 controlled stochastic maps 作为主要算法对比依据。

## 顶层结构

```text
RL_Project_Submission_FINAL_20260507/
|-- code/                  # 可复现实验代码
|-- figures/               # 报告图与补充图
|-- results_csv/           # 实验结果表
|-- docs/                  # 中文说明、QA、图像阅读指南
|-- report_overleaf_light/ # 可直接上传 Overleaf 的轻量报告
```

## code

`code/core/`

- `enhanced_frozenlake.py`：核心环境、算法、训练与评估逻辑。

`code/experiments/`

- `run_standard_4x4_focused.py`：标准 4x4 slippery 实验。
- `run_random8_learning_curves.py`：controlled 4x4 / controlled random 8x8 长预算实验。
- `run_gymnasium8_experiments.py`：Gymnasium 8x8 诊断实验。
- `designed_random_map_experiments.py`：设计随机地图与可信度检查相关实验。

`code/analysis/`

- `make_long_budget_report_assets.py`：根据长预算结果生成报告图表。
- `make_stochastic_report_assets.py`：早期 stochastic 汇总图生成脚本。
- `plot_standard_4x4_slippery.py`：标准 4x4 图像生成脚本。

## figures

`figures/01_report_used_compact/`

- 轻量版报告图片，供 Overleaf 编译使用。
- 与 `report_overleaf_light/main.tex` 中引用的图片一致。

`figures/02_main_controlled_results/`

- 主实验图。
- 包含标准 4x4、designed 4x4、controlled random 8x8、ablation、Optuna 图。
- 这是报告和演讲中最应该重点讲的部分。

`figures/03_diagnostic_gymnasium8/`

- Gymnasium 8x8 诊断实验图。
- 用来说明：直接使用随机地图生成器时，很多低 p 地图虽然连通，但 oracle success 接近 0，不适合做算法 ranking。

`figures/04_supplemental_per_map/`

- 补充逐地图学习曲线。
- 用来回答“为什么方差大”“某张图是否拖累平均值”等 QA。

`figures/05_all_figures_archive/`

- 当前 clean 包中的全部有效图像归档。
- 包含分 p 曲线、Gymnasium 每张地图曲线、contact sheet、所有 heatmap 等。
- 如果需要找旧图或补充图，优先到这里看。

## results_csv

`results_csv/01_main_controlled/`

- 主实验 CSV。
- 包含 standard 4x4、designed 4x4、controlled random 8x8、ablation、Optuna 结果。
- Optuna 主结果使用 `optuna_tuned_validation_scores.csv`，不使用早期包含 Double Q 异常值的 screening 表。

`results_csv/02_diagnostic_gymnasium8/`

- Gymnasium 8x8 诊断实验 CSV。
- 包含每张地图的 oracle、最终成功率、学习曲线与地图 manifest。
