# 文档入口

建议按下面顺序阅读：

1. `文件结构说明.md`  
   了解这个 GitHub 上传版包含哪些文件、每个目录做什么。

2. `中文结果整理.md`  
   快速了解实验设置、主要结果和结论。

3. `gymnasium8_benchmark_update.md`
   最新 Gymnasium 8x8 harder random-map 结果。这个文件解释为什么旧 custom random maps 偏容易，以及新结果如何修正结论。

4. `图像索引与阅读指南.md`  
   解释每张核心图应该怎么看，适合写报告或准备展示。

5. `algorithm_qa_notes.md`  
   逐个算法解释优劣势，适合答辩 QA。

6. `ablation_study_plan.md`  
   解释 exploration、reward propagation 和 map difficulty ablation。

7. `EXPERIMENT_FOLDER_MAP.md`  
   说明实验路线从 baseline 到 long-budget random 8x8 的演进。

8. `中文文件层级与说明.md`  
   中文版目录说明，与 `文件结构说明.md` 内容接近，方便组员阅读。
