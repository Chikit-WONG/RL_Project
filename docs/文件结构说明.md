# 文件结构说明

这个文件夹是面向 GitHub 分支上传的整理版。它保留当前 stochastic FrozenLake 主线需要的代码、图像、CSV 和说明文档。

## 顶层结构

```text
.
|-- README.md
|-- GITHUB_BRANCH_WORKFLOW.md
|-- code/
|-- figures/
|-- results_csv/
|-- docs/
```

## `code/focused_random_map/`

可运行代码目录。

- `enhanced_frozenlake.py`：FrozenLake 环境和 tabular RL 算法。
- `map_env_utils.py`：显式地图环境、随机地图生成和评估。
- `run_standard_4x4_focused.py`：标准 4x4 slippery 实验。
- `plot_standard_4x4_slippery.py`：标准 4x4 绘图。
- `designed_random_map_experiments.py`：受控随机地图生成与 designed 4x4 实验。
- `run_random8_learning_curves.py`：designed 4x4 / random 8x8 long-budget 曲线。
- `make_long_budget_report_assets.py`：根据 CSV 生成图表和汇总表。
- `requirements.txt`：Python 依赖。
