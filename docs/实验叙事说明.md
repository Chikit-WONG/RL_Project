# 实验叙事说明

## 一句话版本

我们先使用 Gymnasium 标准 8x8 作为重要标准基准；随后尝试直接使用 Gymnasium 随机地图，但发现很多低 p 随机图在 slippery dynamics 下 oracle success 也接近 0，无法公平比较算法；因此我们转向 controlled stochastic maps，并在这些可学习、可复现、非平凡的地图上系统比较多种 tabular RL 算法。

## 为什么 Gymnasium 标准 8x8 很重要

Gymnasium 标准 8x8 是本项目的重要 sanity check 和标准对比图。它不是失败案例。它的价值在于：

- 地图固定、可复现；
- 被很多 FrozenLake 教程和实现使用；
- 在 `slippery=True` 下有明显随机性；
- oracle success 不是 1，也不是接近 0；
- 可以检验训练 pipeline 是否正常。

因此报告中应把 Gymnasium 标准 8x8 单独讲清楚，再讨论 Gymnasium random maps 的问题。

## 为什么 Gymnasium 随机图不是主对比

Gymnasium `generate_random_map` 可以保证存在从起点到终点的路径，但这只是 deterministic reachability。FrozenLake 在 `slippery=True` 时，每次动作都有概率偏转，因此“有路径”不代表“最优策略成功率高”。

在我们的诊断实验中，很多 `p=0.5` 和 `p=0.6` 的 8x8 随机图：

- oracle success 接近 0；
- 所有 model-free 方法也接近 0；
- 结果无法区分算法优劣。

所以它们更适合作为 stress test，而不是主 ranking benchmark。

## 为什么 controlled maps 合理

controlled maps 的目标不是把问题变简单，而是让比较有效：

- 所有地图都是 `slippery=True`；
- 仍然是 sparse reward；
- 仍然存在随机转移；
- 但 oracle 显示地图具有合理可解性；
- 多张地图可以检验泛化和稳定性。

因此，controlled random 8x8 是当前报告的主算法对比环境。

## 最终主结论

- Optimistic Q-learning 在 controlled random 8x8 上表现最好，接近 oracle。
- Expected SARSA、SARSA、Q-learning 是强 baseline 组。
- Dyna-Q 的最终成功率不一定最高，但 AUC 和早期学习速度有优势。
- Gymnasium 诊断实验说明：地图生成方式本身会极大影响 FrozenLake 结论。
