# 图像索引与阅读指南

所有正式图像位于：

```text
figures/main/
```

## 推荐主图

### `stochastic_success_heatmap.png`

用途：总体展示不同算法在主要环境上的成功率。

读法：行是算法，列是环境设置，格子数字是 mean success。适合作为报告或展示的第一张结果图。

### `random8_learning_curves_all_maps_panel.png`

用途：展示 20 张 random 8x8 map 上的学习曲线。

读法：每个小图是一张地图；横轴是 training episode，纵轴是 greedy evaluation success rate；黑色虚线是 Value Iteration oracle。它最适合解释为什么平均曲线方差很大。

### `random8_final_success_heatmap_by_map.png`

用途：比较每个算法在每张 random 8x8 map 上的最终成功率。

读法：每列是一张地图，每行是算法。可以快速看出某个算法是否只在少数地图失败。

### `random8_oracle_gap_heatmap_by_map.png`

用途：判断算法距离 oracle 还有多远。

读法：数值是 `oracle success - learned success`。越接近 0 越好。如果 oracle 高但 gap 大，说明地图可解，但算法没有学好。

### `random8_auc_heatmap_by_map.png`

用途：比较训练全过程表现，而不仅是最后一个点。

读法：AUC 越高，表示训练期间整体表现越好。Dyna-Q 的 planning 优势通常在这张图中更明显。

## 辅助图

### `random8_convergence_episode_heatmap.png`

用途：比较算法达到 `success >= 0.80` 的速度。

读法：数字越小越快；`--` 表示没有达到阈值。

### `random8_final_success_points_by_probability.png`

用途：解释同一个 frozen tile probability 下仍然存在地图差异。

读法：每个点是一张地图，而不是均值。适合回答“为什么同一 p 下方差仍然很大”。

### `random8_learning_curves_p0.80.png` 到 `random8_learning_curves_p0.95.png`

用途：按 frozen tile probability 分组查看曲线。

读法：每张图包含同一 p 下 5 张地图的学习曲线，适合作为附录或答辩备用。

### `random8_mean_learning_curve.png`

用途：展示跨 20 张 random 8x8 maps 的平均趋势。

注意：平均曲线会隐藏地图间差异，不建议单独作为主要证据。

## Ablation 与调参图

### `exploration_ablation_fixed_8x8.png`

用途：说明 exploration 策略对结果的影响，尤其是 Optimistic Q-learning 为什么强。

### `reward_propagation_ablation_fixed_8x8.png`

用途：说明 eligibility traces 和 planning 对稀疏奖励传播的影响。

### `optuna_best_scores.png`

用途：展示 Optuna 超参数搜索的最佳分数。
